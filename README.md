# 🐛 Cute Worms - Game Cacing & Buah Segar 🍉

Game Cacing/Snake bertema ceria dan lucu yang dibuat menggunakan HTML, CSS, dan JavaScript murni dalam satu file tanpa dependensi tambahan.

## ✨ Fitur Utama
- **Gambar Ilustrasi Vektor Buah Asli**: Makanan cacing berupa buah-buahan segar bergambar asli (Semangka, Stroberi, Pisang, Anggur, Jeruk, Apel Merah, Apel Hijau, Nanas, Ceri, Alpukat, Lemon, Persik) lengkap dengan efek bayangan 3D dan animasi membal (*bounce*).
- **Animasi Mulut Cacing (Chomping)**: Kepala cacing memiliki animasi membuka-menutup mulut (*nom-nom*) dan terbuka ekstra lebar penuh antusiasme saat mendekati buah segar.
- **Pilihan Karakter Cacing Lucu**:
  - 🍓 Mimi Berry (Stroberi Pink)
  - 🥑 Mochi Matcha (Alpukat/Matcha)
  - 🦄 Rainbow Sky (Pelangi Ajaib)
  - 🐝 Bubu Bee (Lebah Madu)
  - 🧋 Taro Boba (Boba Manis)
  - 🍬 Blueberry Fluff (Permen Kapas)
- **Audio Efek Gemas**: Suara makan ceria (*cute chimes*) yang disintesis langsung dengan Web Audio API.
- **Skor & Rekor Tertinggi**: Tersimpan otomatis di browser (`localStorage`).
- **Kontrol Lengkap**: Keyboard (Panah / WASD / Spasi) dan Touch D-Pad virtual untuk layar sentuh / smartphone.

## 🚀 Cara Menjalankan
Cukup buka file `index.html` langsung di browser mana pun (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari, dll.). Tidak memerlukan instalasi atau server tambahan!
